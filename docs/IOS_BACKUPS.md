# iOS 备份取证

## 添加与浏览

添加检材时选择「文件夹」，定位到同时包含 `Manifest.plist` 和 `Manifest.db` 的单个
iTunes / Finder / MobileSync 备份目录（通常以设备 UDID 命名），不要选它的父目录。

未加密备份直接展示 `HomeDomain/Library/SMS/sms.db`、`AppDomain-…/Documents/…`
等原始域与相对路径。缺失的父目录按清单路径补齐；`__backup` 保留原始控制文件供独立复核。
文件内容走原有只读预览、文件搜索、哈希、目录快照和导出管线。它仍是逻辑证据，没有分区、
连续扇区字节流或 RAW 镜像哈希；整盘雕刻不适用于该视图。

## 加密备份

加密备份先展示原始备份目录。进入「镜像信息」中的「iOS 备份」卡片，输入备份密码，
点击「解锁并打开」。密码也允许为空。正确密码创建 `decrypted://ios/…` 只读子会话，
源证据保持登记；关闭源证据会关闭所有解锁子会话。密码与解锁状态不写入案件，
重新启动应用后需要重新解锁。密码不会进入日志，后端凭据和密钥采用 zeroize 清理。

清单在内存中解密，文件按需解密；读取器不生成解密临时证据。原有预览机制仍可能为媒体、
文档等物化预览缓存，显式导出也会写出明文，这些遵循既有缓存和导出生命周期。
CBC 范围读取借用前一个密文块恢复 IV，SQLite 等分页预览不必扫描整个文件前缀。
清单长度优先于 PKCS#7；未记录长度时按上游策略检查末块填充。已知长度的截断文件明确失败，
不返回成功的完整文件或摘要。

## 异常检查与导出

「检查备份」调用上游异常审计器，展示加密声明与实际状态矛盾、缺失/孤立数据文件、
文件 ID 与路径 SHA-1 不一致、未完成备份和缺失预期应用域等观察。
结果保留观察代码、严重程度、证据字段和分析器版本；应用域缺失保持「未评级」，
不能据此断言人为删除。检查结果属于当前信息页的临时结果，可点击「导出 JSON」保存完整报告，
包含证据路径、设备元数据、导出时间和上游观察；CLI 也可保存返回的完整 JSON。
无法识别的清单行、无法确定长度的文件会在界面明确提示，需结合原始清单复核。

## 取消与资源边界

解锁与检查登记到即时任务管理器。检查在遍历中响应取消；PBKDF2 无法在派生阶段内部打断，
取消后会在该阶段结束时停止，且不会发布解锁子会话。密钥派生的任一迭代参数超过
2000 万轮会明确拒绝，避免不可信清单触发无界计算。

## CLI

两个命令与桌面共用实现：

- `ios-backups unlock [--password]`（`ios_backup_unlock`）：作用于 `--image` 指定的备份，可选 `--task-id`；
  返回解锁会话的 `ImageInfo`。单写 `--password` 时在终端中以遮盖方式提问，或读取管道传入的标准输入。
- `ios-backups audit`（`ios_backup_audit`）：可选 `--task-id`；返回上游观察数组。

在 `shell` 或 JSONL 会话中先 `images open` 备份，再解锁，并用返回的子会话 ID 浏览或检查。
不要将密码写入共享脚本、报告或命令行历史。

## 来源与验证

读取器与审计器来自 [SecurityRonin/ios-backup-forensic](https://github.com/SecurityRonin/ios-backup-forensic)，
固定到 `8d8cef447ae212e7dd22dc0425156bf4ddfcfa05`，保存在 `src-tauri/vendor/ios-backup`，
遵循 Apache-2.0。与现有 `sqlite-core` 共用依赖。局部修改及样本来源见该目录的 `UPSTREAM.md`。

`just test-ios-backup` 覆盖上游解析、密码、独立加密样本、加密声明矛盾、路径安全、
未知长度及流/范围读取；`just test` 覆盖 LovelyCarve 的文件树、会话、短读和异常映射；
`just test-fe` 覆盖密码清理、取消和切换证据时的迟到结果回收。
当前验证包含人工合成并由独立 Python 加密实现生成的样本，尚不能代替真实设备备份与已知密码的
逐字节验证。当前范围是带 `Manifest.db` 的现代本地备份，不包括旧 `Manifest.mbdb`、
iCloud 下载、备份创建、密码破解或短信/联系人等业务数据库的专门报告解析。
