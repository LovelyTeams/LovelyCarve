# LittleFS

LovelyCarve 可只读浏览 LittleFS 2.0 和 2.1 的逻辑块镜像，以及分区表标出的 LittleFS 分区。读取器为纯 Rust。

## 支持范围

- 从校验通过的超级块读取块大小和块数。探测支持 128 字节至 64 KiB 的块，已用官方实现验证 128、512 和 4096 字节三种块大小。超出声明块数的镜像尾部保留在原始检材中。
- 校验元数据提交的 CRC，逐对选择较新的有效副本。支持拆分目录、超级块搬迁后的根目录查找和提交中的创建、删除与重命名记录。遇到待完成的跨目录移动时，在内存浏览视图中隐藏原位置。
- 文件可预览、按范围读取、哈希和导出。短文件直接读取内联数据，大文件使用 CTZ 跳表定位逻辑偏移。数据块没有独立校验和，读取会检查分配地址、卷边界与元数据块冲突。
- 文件名区分大小写。有效 UTF-8 原样显示，原始的非 UTF-8 字节、控制字符、反斜线和百分号使用 `%HH` 显示。路径应使用文件列表呈现的名称。

## 限制与验证

- LittleFS v1、穿插 NAND 备用区或 ECC 的转储，以及需要专用固件分区表才能定位的整片闪存，需要先按对应布局提取逻辑块镜像。镜像无标准文件时间戳，自定义属性内容不解释为时间，也不作为命名流展示。当前无需修改检材来完成显示，不提供删除恢复或孤儿目录重建。
- `just test-vendor littlefs-reader` 和 `just clippy-littlefs` 验证独立读取器，覆盖备用元数据块、损坏的 CTZ 指针，以及跨目录移动中途掉电。CLI 测试也检查原始分区几何、MBR、跨块范围、哈希和导出。测试镜像来自 [LittleFS 官方 v2.11.0](https://github.com/littlefs-project/littlefs/tree/v2.11.0)，版本及哈希见[读取器来源记录](../../src-tauri/vendor/littlefs-reader/ORIGIN.md)。
