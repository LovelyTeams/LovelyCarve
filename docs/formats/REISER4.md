# Reiser4

LovelyCarve 通过 `reiser4-reader` 只读打开 4 KiB、Format40 4.0.0–4.0.2 的干净单设备卷。裸卷和分区都使用 `reiser4` 类型。[ReiserFS 3.5 / 3.6](REISERFS.md) 由独立读取器处理。

| 能力 | 范围 |
| --- | --- |
| 卷与树 | 主超级块、格式超级块、状态和日志头尾，短键和长键，node40 和带 CRC32C 的 node41，按对象键区间走树 |
| 目录与元数据 | cde40 聚集目录项、内联短名和存储在条目中的长名，硬链接、符号链接、文件模式、UTC 秒级修改／访问／状态变更时间 |
| 内容 | plain40 尾部打包、extent40 区段和 ctail40 簇。ctail40 支持 4–64 KiB 簇、LZO、原始 DEFLATE、Zstandard、未压缩簇和稀疏簇。支持范围读取、流式读取、哈希和导出 |
| 校验 | 对所访问的节点检查级别、分隔键、排序和范围，对数据区段检查分配位图及其 Adler-32、卷边界、逻辑大小和物理重叠。读取压缩簇时验证片段连续性、压缩数据的 Adler-32 和解压后的长度 |

有待回放或修复的卷会报错。文件加密、Reiser5 多设备、ACL、扩展属性的解码和删除记录恢复尚未支持。目录名通过现有的 UTF-8 路径接口提供，无法表示的名称会报错。一次对象查询最多访问 131072 个树页并载入 64 MiB item 数据。范围读取只解压与请求相交的簇。extent40 的显式空洞与 ctail40 中未分配的整簇均按格式规则补零。

两份未压缩 4.0.2 卷通过 `fsck.reiser4 --check`，并由上游工具列举目录和导出文件。三份压缩样本由原生内核写入后以只读方式重新挂载并记录 SHA-256。`just test-vendor reiser4-reader` 验证这些样本的内容、范围读取和损坏检查。`just test-cli` 验证裸卷与 MBR、路径和节点 ID、符号链接、压缩文件的范围读取、哈希和导出。[样本来源](../../src-tauri/vendor/reiser4-reader/ORIGIN.md)
