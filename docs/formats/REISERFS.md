# ReiserFS v3（3.5 / 3.6）

`reiserfs-reader` 是纯 Rust 只读库。适配前先检查了 rusty-backup 的 v3 读取器及
unearth 0.4.0；后者只有签名 / 超级块识别，没有目录和内容读取。因此基于前者的格式定义
改造读取路径，并对照 Linux v6.12 的磁盘结构语义加固。固定提交与许可见
[ORIGIN.md](../../src-tauri/vendor/reiserfs-reader/ORIGIN.md)。不链接 C 文件系统代码、
内核驱动或主机文件系统挂载接口。

## 能力

| 项目 | 范围 |
| --- | --- |
| 格式 | 小端 ReiserFS 3.5 / 3.6；`ReIsErFs` / `ReIsEr2Fs`，以及从 `s_version` 判断格式的 `ReIsEr3Fs` |
| 识别 | 裸卷 / 分区细化；8192 和 65536 字节超级块；1 / 2 / 4 / 8 KiB 块；旧式连续及新式分布位图 |
| 树 | S+tree 内部节点与叶节点；按对象键区间裁剪遍历；混合 v1 / v2 键；校验层级、父子界限、最小键、子节点占用大小、排序、循环及 item 身体边界 |
| 目录 | 多 item / 多叶目录、可见位、`.` / `..`、硬链接、改名后的 locality ID；保留 `.reiserfs_priv` 元数据目录；名称大小写敏感，反斜杠作为名称字节保留 |
| 内容 | stat-data v1 / v2；间接数据块、显式零指针稀疏区、直接 item 尾部打包；连续物理块 / 空洞合并；完整 / 流式 / 范围读取使用同一逻辑映射 |
| 链接 | 保留符号链接目标，不交给主机跟随；读取器区分设备 / FIFO / socket，拒绝将其作为普通内容读取 |
| 时间 | 分别保留 atime / mtime / ctime 的 UTC 秒精度；无 birth time；32 位磁盘秒不截断为有符号 2038 时间 |
| 工作流 | 浏览、预览、文件哈希、导出、自动目录快照 / 索引、CLI；独立 `reiserfs` 分区类型 |

目录项携带的 `(dir_id, object_id)` 是完整身份。`dir_id` 不能当成当前父目录 inode；
硬链接的路径节点不同，但 inode 身份相同。根目录 `..` 使用特殊 `(0,1)` 对象。

只从已分配且位于卷内的块读取内容；保留源读取错误。空洞仅来自明确的零块指针；
缺失 item、逻辑缺口、越界 / 重复块、尾部不足和短读都报错。历史 `i_blocks` 存在配额
记账差异，不用它代替实际映射或凭其值补零。

## 限制

- **Reiser4 不等于 ReiserFS v3，仍未支持。**
- dirty / 未干净卸载卷明确拒绝；不回放内部或外部日志，不执行修复、写入或删除恢复。
  干净的 relocated / 外部日志卷使用已提交的主树；不打开日志设备，也不验证日志历史。
- 不解码 ACL / xattr 语义或搜索历史版本；原生 `.reiserfs_priv` 目录保持可见。
- 当前应用节点模型没有设备 / FIFO / socket 类别，界面以零大小文件项表示；尝试读取内容会明确失败。
- 非 UTF-8 文件名或符号链接目标无法通过当前字符串契约无损表示，会明确报错，不替换成乱码；
  不支持带嵌入 stat-data 的古老目录项。目录哈希值按磁盘顺序保留，不做哈希算法重算审计。
- 单对象元数据最多 64 MiB、遍历最多 65536 个树页、目录最多 100 万个可见项；
  达到限制明确失败。位图 / 树页 / stat 缓存分别为
  8 / 64 / 128 项，仅保留最近一个目录和文件映射。范围读按映射定位，不从文件头流式跳过。
- 不宣称完整 fsck 或全卷块所有权审计；校验所访问的结构、分配状态和单文件块重叠。

## 验证

- `just test-reiserfs` / `just clippy-reiserfs`：外部 mkfs.reiserfs / guestfish 镜像；独立
  3.5 / 3.6、四种块大小、两种位图布局、混合内部键、多层树与跨叶对象、尾部 / 稀疏、
  大于 4 GiB 的稀疏映射、隐藏项、硬链接、Unicode / 反斜杠、时间、范围读及损坏拒绝。
- `just generate-reiserfs-fixtures`：独立 Python 编码最小结构，记录样本哈希；
  需要 Python 的 `zstandard` 包来校验保留的外部压缩样本。
  自制样本不是 formatter / fsck oracle。真实 v3.5 卷、真实 1 / 2 / 8 KiB 卷和真实大型卷
  尚未做独立逐文件对照，不能用自制样本替代这一边界。
- 原生工作流测试覆盖裸卷 / MBR、全读 / 范围 / 流式一致、导出不覆盖、dirty 拒绝与源字节不变；
  快照测试检查路径、时间和硬链接；`just test-cli` 验证两类布局的读取、SHA-256、导出及名称。

格式参考：[Linux v6.12 ReiserFS](https://kernel.googlesource.com/pub/scm/linux/kernel/git/torvalds/linux/+/refs/tags/v6.12/fs/reiserfs/)。
