# GFS1

LovelyCarve 以纯 Rust 只读打开 Red Hat GFS1（文件系统 1309、multihost 1401）。可打开裸卷及分区内的完整卷，分区位置仍以原检材字节为准。

- 读取超级块中的根 inode、rindex 和 jindex。按资源组位图验证 inode、间接块、目录叶及数据块的分配状态。
- 支持内联线性目录和 exhash 目录，校验名称散列、桶范围、碰撞叶链和 inode 身份。目录查找区分大小写。名称当前须为有效 UTF-8。
- 支持内联数据、多级间接块、硬链接、符号链接和 journaled-data 块。范围读取在逻辑 EOF 截止，稀疏空洞按格式补零。保留秒级 UTC 访问、修改与状态变更时间。
- 检查每个 journal 的日志段头及其副本，依据事务序号判断清洁状态。需要重放、日志头副本不一致、分配范围越界和超过读取上限时明确报错。

目前覆盖干净的离线卷。日志重放、在线集群协调、已删除文件恢复和扩展属性读取尚未覆盖。每卷最多检查 256 个日志与合计 1048576 个日志段头。原生样本验证了 512 和 4096 字节块。

`just test-vendor gfs1-reader` 和 `just clippy-gfs1` 验证读取器。CLI 用例核对裸卷、MBR、目录、链接、稀疏范围、哈希和导出。上游 `gfs_debug` 另外核对了文件的完整字节。[样本来源与验证记录](../../src-tauri/vendor/gfs1-reader/ORIGIN.md)
