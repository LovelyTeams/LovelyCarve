# Encrypted image integration fixtures

Generated by `scripts/make-encrypted-fixtures.py` using Python cryptography / OpenSSL,
independently of the production Rust readers. Public test password: `lovelycarve-test`.
VeraCrypt PIM: **1**; `hidden.hc` uses the hidden header at 65536 bytes.
LUKS1 uses PBKDF2-SHA256; LUKS2 uses Argon2id and 4096-byte encryption sectors.
All four images decrypt to `plain.img` (FAT12 with `HELLO.TXT`). See `sha256.json`.
The deliberately tiny KDF costs are for regression tests only.

These are synthetic format fixtures, not evidence acquired from a real system.
The public cryptsetup VeraCrypt corpus is tested separately and is not redistributed here.

Verification: `just test encrypted_image_tests`, `just test-cli`; standalone reader
suites: `just test-luks --release`, `just test-veracrypt --release`. Optional real
VeraCrypt oracle inputs use `VC_ORACLE` / `VC_HIDDEN_ORACLE`, documented in the
vendored upstream `tests/data/README.md`. Unset oracle paths cause those upstream
tests to return early; a green aggregate alone does not prove oracle execution.
